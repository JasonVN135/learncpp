# Contact Book

The goal of this project is similar to tohe previous project. We want to be able to store contacts with names, phone numbers, and email addresses. With this new project, we will add functionality to searching and editing, along with previously viewing and deleting.

## 1. Functional Requirements

1. Add a contact

The user enters a contact's name, phone number, and email address.
- Name can not be empty, but phone number and email can optionally be empty
- Each contact should still have a unique ID
- Phone numbers should be supported by a variety of formats

2. List contacts with filters

3. Edit existing contacts

4. Delete contacts

5. Exit application
